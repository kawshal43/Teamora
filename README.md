# Teamora

**Teamora** is a modern workforce management and internal workplace social platform built for high-performing teams.

---

## 🚀 Key Features

- **Worksheet V2.0 (Employee & Admin Views)**
  - Continuous absolute time grid (8:00 AM – 9:00 PM) with 5-minute precision.
  - Interactive mouse edge resizing for start time (top edge) and duration (bottom edge).
  - Drag-and-drop task rescheduling across days and hours.
  - Multi-task clustering with automatic side-by-side overlap rendering.
  - Day, Week, and Month segmented calendar views with full date navigation.

- **Live Task Tracking & Floating Draggable Pill**
  - Real-time active task tracking with live stopwatch ticker.
  - Non-intrusive floating draggable pill widget.
  - Quick task switching with automatic completion and confirmation prompts.

- **Admin Oversight & Audit History**
  - Team Overview with real-time employee work statuses.
  - Individual Employee Calendar inspection.
  - Detailed task inspection and complete revision audit trail for time adjustments.

- **Workplace Social Feed & Engagement**
  - Company announcements, departmental posts, likes, and comments.

- **Attendance & Time Tracking**
  - Digital check-in/check-out with session history and correction requests.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State & Storage**: React Context + LocalStorage persistence

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
